Описание проекта
Информационная система «Автомастерская» предназначена для автоматизации работы сервисного центра «АвтоСервис». Система обеспечивает учёт клиентов, автомобилей, договоров, нарядов-заказов, оказанных услуг и используемых запчастей. Также предусмотрено формирование отчётов и статистики по выполненным работам.

Технологии
Язык программирования: Python
Фреймворк: Django
REST API: Фреймворк Django REST Framework
Установка

Клонируйте репозиторий:
git clone https://github.com/Arthur24519/Project.git
cd AutoServis

Создайте виртуальное окружение:
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
venv\Scripts\activate  # Для Windows

Установите зависимости:
pip install -r requirements.txt

Настройте базу данных:
Убедитесь, что PostgreSQL установлен и запущен.
Создайте базу данных Auto_Service.

Настройте файл settings.py:
Убедитесь, что параметры подключения к базе данных указаны правильно.

Примените миграции:
python manage.py migrate

Запустите сервер:
python manage.py runserver

Использование
Регистрация клиентов: Пользователи могут регистрировать новых клиентов и их автомобили.
Оформление договоров: Система позволяет оформлять договоры на обслуживание.
Учет услуг и запчастей: все оказанные услуги и использованные запчасти фиксируются в системе.

API
Примеры эндпоинтов:

GET /api/clients — получение списка клиентов.
POST /api/clients — создание нового клиента.
Аналогичные эндпоинты для остальных сущностей.

Тестирование
Для запуска тестов используйте команду:
pytest
