# Описание проекта

## Информационная система «Автомастерская» предназначена для автоматизации работы сервисного центра «АвтоСервис». Система обеспечивает учёт клиентов, автомобилей, договоров, нарядов-заказов, оказанных услуг и используемых запчастей. Также предусмотрено формирование отчётов и статистики по выполненным работам.

# Технологии
```
Язык программирования: Python

Фреймворк: Django

REST API: Фреймворк Django REST Framework
```
# Установка

1. Клонируйте репозиторий:
```
git clone <URL_репозитория>

cd AutoServis
```
2. Создайте виртуальное окружение:
```
python -m venv venv

source venv/bin/activate  # Для Linux/Mac

venv\Scripts\activate  # Для Windows
```
3. Установите зависимости:
```
pip install -r requirements.txt
```
4. Настройте базу данных:
```
Убедитесь, что PostgreSQL установлен и запущен.

Создайте базу данных Auto_Service.
```
5. Настройте файл settings.py:
```
Убедитесь, что параметры подключения к базе данных указаны правильно.
```
6. Примените миграции:
```
python manage.py migrate
```
7. Запустите сервер:
```
python manage.py runserver
```
# Использование

1. Регистрация клиентов: Пользователи могут регистрировать новых клиентов и их автомобили.

2. Оформление договоров: Система позволяет оформлять договоры на обслуживание.

3. Учет услуг и запчастей: все оказанные услуги и использованные запчасти фиксируются в системе.

# Тестирование

Для запуска тестов используйте команду:
```
pytest
```
